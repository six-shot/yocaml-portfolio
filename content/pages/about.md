# About Me

My journey in software development began with a fascination for how things work behind the scenes. I started with basic web technologies and gradually expanded into more complex frameworks and tools. Today, I work with:

- **Modern JavaScript** (ES6+, TypeScript)
- **React & Next.js** for dynamic web applications

- **Three.js** for 3D web experiences
- **Node.js** for backend development
